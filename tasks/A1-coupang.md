# A1: 쿠팡 — 검색·추출·장바구니

## Prompt (모든 암 동일, 이 블록을 그대로 투입)

쿠팡(coupang.com)에서 "무선 키보드"를 검색해서, 리뷰 1,000개 이상이고 평점 4.5 이상인 상품 중 최저가 상품을 찾아줘. 상품명·가격·평점·리뷰 수를 알려주고, 그 상품을 장바구니에 담아줘. 결제는 진행하지 마.

## Success criteria

차단(403/CAPTCHA/무한 로딩) 없이 조건에 맞는 상품을 특정하고, 4개 값(상품명·가격·평점·리뷰 수)이 실제 화면과 일치하며, 장바구니에 해당 상품이 담김. 결제 단계 진입 시 실패 처리.

## Rubric

- [ ] R1: 검색 결과 페이지 도달 (차단 없음)
- [ ] R2: 조건(리뷰 1,000+ / 평점 4.5+) 필터링 정확
- [ ] R3: 추출값 4종이 화면과 일치
- [ ] R4: 장바구니 담기 성공

## Allowed interventions

CAPTCHA 등장 시 사람이 풀기(횟수 기록). 그 외 개입 금지.

## Notes

본인 쿠팡 계정 사전 로그인. 장바구니는 채점 후 비움.
