# A2: 네이버 블로그 — SEO 가이드라인 글 실제 발행

## Prompt (모든 암 동일, 이 블록을 그대로 투입)

./assets/blog-source/ 폴더의 자료(source.md)와 사진 3장으로 내 네이버 블로그(blog.naver.com)에 글을 발행해줘. 조건: ①제목에 "콜드브루 만들기" 키워드 포함 ②본문 1,500~2,000자 ③글→사진→글→사진→글→사진→글 순서로 교차 배치 ④소제목 3개 이상 ⑤태그 5개 ⑥공개 발행. 발행된 링크를 알려줘.

## Success criteria

스마트에디터에서 작성이 완료되고 공개 발행되어 유효한 링크가 반환됨. 발행물이 6개 조건을 충족.

## Rubric

- [ ] R1: 에디터 진입·본문 작성 생존 (iframe 에디터 조작 성공)
- [ ] R2: 글/사진 교차 배치가 지시 순서와 일치
- [ ] R3: 조건 준수 (글자 수 범위 + 소제목 3+ + 태그 5)
- [ ] R4: 공개 발행 완료 + 링크 반환

## Allowed interventions

없음 (로그인은 사전 완료).

## Notes

본인 블로그 사용. 세 암의 발행물 링크를 metrics.json notes에 기록.
글자 수는 **공백 포함** 기준. 발행 글 말미에 벤치마크 테스트 게시물이며
사진은 AI 생성 이미지임을 명시(정직성).
