# A3: 네이버 지도 — 조건 복합 탐색 → 비교표 → 예약 직전

## Prompt (모든 암 동일, 이 블록을 그대로 투입)

네이버 지도(map.naver.com)에서 다음 주 토요일 저녁 6시, 강남역에서 도보 10분 이내, 4인, 주차 가능, 네이버 예약이 되는 한식당을 찾아줘. 후보 3곳을 평점·리뷰 경향·가격대 비교 표로 정리하고, 1순위 가게의 네이버 예약 화면에서 날짜·시간·인원까지 선택해줘. 최종 예약 확정 버튼은 누르지 마.

## Success criteria

조건을 충족하는 실존 한식당 3곳의 비교표가 실데이터로 산출되고, 1순위 가게의 예약 위젯에서 날짜·시간·인원 선택 상태에 도달. 예약 확정 시 실패 처리.

## Rubric

- [ ] R1: 조건 충족 후보 3곳 발굴 (지도 iframe 탐색 생존)
- [ ] R2: 비교표 3항목(평점·리뷰 경향·가격대)이 3곳 모두 실데이터
- [ ] R3: 네이버 예약 위젯 진입
- [ ] R4: 날짜·시간·인원 선택 도달 (확정 직전 정지)
