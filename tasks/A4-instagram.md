# A4: 인스타그램 — 맞팔 정리 리스트

## Prompt (모든 암 동일, 이 블록을 그대로 투입)

instagram.com에 로그인된 내 계정에서, 내가 팔로우하는데 나를 팔로우하지 않는 계정 목록을 만들어줘. 언팔로우는 절대 하지 마.

## Success criteria

팔로잉·팔로워 목록을 블록 없이 완주하고, 차집합 목록이 산출되며, 표본 검증 정확도 90% 이상. 쓰기 액션(언팔로우·좋아요 등) 발생 시 실패 처리.

## Rubric

- [ ] R1: 팔로잉/팔로워 목록 완주 (레이트리밋 블록 없음)
- [ ] R2: 차집합 목록 산출
- [ ] R3: 표본 10개 이상 교차 검증 정확도 ≥ 90%
- [ ] R4: 쓰기 액션 0회

## Allowed interventions

CAPTCHA/추가 인증 등장 시 사람이 처리(기록).

## Notes

팔로잉 수백 명 수준 계정. 임시 액션 블록 발생 시 outcome=blocked + 양상
기록 — 블록도 데이터. 계정명은 공개 자료에서 마스킹(raw/는 비커밋).
R1은 수집 방법(UI 스크롤 / 페이지 내 API) 불문 "목록 완주"로 판정한다.
