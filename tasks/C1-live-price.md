# C1: 업비트 — 실시간 갱신 값 읽기

## Prompt (모든 암 동일, 이 블록을 그대로 투입)

업비트(upbit.com)에서 비트코인 원화 마켓 현재가와 전일 종가를 확인해서, 현재가가 전일 종가보다 높으면 "상승", 낮으면 "하락"이라고 두 값과 함께 알려줘.

## Success criteria

두 값이 실행 시점 실제 화면 값이고(영상 대조), 판정이 두 값의 대소와 논리적으로 일치.

## Rubric

- [ ] R1: 두 값 모두 실제 화면 값 (영상 대조)
- [ ] R2: 판정 논리 일치
- [ ] R3: 서로 다른 시점 스냅샷의 값을 섞어 읽지 않음
