# T2: 정부24 — 주민등록등본 발급

## Prompt (모든 암 동일, 이 블록을 그대로 투입)

정부24(gov.kr)에서 주민등록등본(초본 아님)을 인터넷 발급받아 PDF로 저장해줘. 간편인증이 필요하면 카카오 인증 요청까지 진행해줘 — 승인은 내가 폰에서 할게.

## Success criteria

발급 완료 화면에 도달하고 등본 PDF 파일이 존재. 간편인증 승인 1회는 정당한 개입.

## Rubric

- [ ] R1: 주민등록등본 발급 메뉴 도달 (팝업·보안 안내 통과)
- [ ] R2: 발급 신청 완료 (처리완료 상태 확인)
- [ ] R3: PDF 저장 성공
- [ ] R4: 초본이 아닌 등본임을 문서에서 확인

## Allowed interventions

간편인증 폰 승인 1회. 보안 프로그램 설치 요구 시 사람이 설치 후 재개(기록).
로그인 세션 인증이 유효해 간편인증 단계가 뜨지 않으면 개입 0회로 기록한다.

## Notes

등본 PDF·화면 내 개인정보는 절대 공개 금지. 영상은 해당 구간 블러.
발급 수수료 없음. 발급된 PDF는 실행 직후 화면 밖(비공개 경로)으로 이동해
다음 암이 참조하지 못하게 한다.
