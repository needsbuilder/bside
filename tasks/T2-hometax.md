# T2: 홈택스 — 전자세금계산서 분기 합계 조회

## Prompt (모든 암 동일, 이 블록을 그대로 투입)

홈택스(hometax.go.kr)에서 2026년 2분기(4월~6월) 전자세금계산서 매출·매입 합계를 조회해줘. 매출과 매입 각각 건수·공급가액·세액 합계를 알려주고, 조회 결과를 엑셀 파일로 내려받아줘.

## Success criteria

매출·매입 각각의 건수·공급가액·세액 합계가 화면 값과 일치하게 보고되고, 엑셀 파일이 실제로 저장됨.

## Rubric

- [ ] R1: 전자세금계산서 합계 조회 메뉴 도달 (레거시 UI·팝업 통과)
- [ ] R2: 기간을 2026-04-01~2026-06-30으로 정확히 설정하고 조회 실행
- [ ] R3: 매출·매입 합계 수치(건수·공급가액·세액)를 정확히 추출
- [ ] R4: 엑셀 파일 다운로드 성공

## Allowed interventions

로그인은 실행 전에 사람이 마쳐둔 상태에서 시작하므로 인증 개입은 원칙적으로
없다. 세션 만료로 재인증 화면이 뜨면 폰 승인 1회만 허용하고 기록한다.

**금지**: 공동인증서 비밀번호 등 크리덴셜 대리 입력은 어떤 암에서도 하지 않는다.
**금지**: 신고서 작성·제출 버튼은 절대 누르지 않는다(조회·다운로드만).

## Notes

조회 전용 과제라 되돌릴 수 없는 행위가 없다. 다운로드된 엑셀과 화면의
사업자번호·거래처명은 공개 자료에서 블러 처리하고, 파일은 실행 직후 비공개
경로로 옮겨 다음 암이 참조하지 못하게 한다.
