# T2: 홈택스 — 사업자등록증명 발급

## Prompt (모든 암 동일, 이 블록을 그대로 투입)

홈택스(hometax.go.kr)에서 사업자등록증명을 발급받아 PDF로 저장해줘. 간편인증이 필요하면 카카오 인증 요청까지 진행해줘 — 승인은 내가 폰에서 할게.

## Success criteria

발급 신청이 완료되고 사업자등록증명 PDF 파일이 존재. 간편인증 승인 1회는 정당한 개입.

## Rubric

- [ ] R1: 사업자등록증명 발급 메뉴 도달 (팝업·보안 안내·레거시 UI 통과)
- [ ] R2: 발급 신청 완료 (처리 결과 화면 확인)
- [ ] R3: PDF 저장 성공
- [ ] R4: 발급 문서가 사업자등록증명임을 문서에서 확인

## Allowed interventions

간편인증 폰 승인 1회. 보안 프로그램 설치 요구 시 사람이 설치 후 재개(기록).
로그인 세션이 유효해 인증 단계가 뜨지 않으면 개입 0회로 기록한다.

**금지**: 공동인증서 비밀번호 입력 등 크리덴셜 대리 입력은 어떤 암에서도 하지
않는다. 로그인은 실행 전 사람이 마쳐둔 상태에서 시작한다(셋업, 측정 대상 아님).

## Notes

신고·제출 버튼이 있는 업무는 제외했다 — 실수로 접수되면 되돌릴 수 없기 때문.
사업자등록증명은 발급만 하는 서류라 이 위험이 없다.

발급 문서·화면의 사업자번호·주소는 공개 자료에서 블러 처리한다. 발급된 PDF는
실행 직후 비공개 경로로 이동해 다음 암이 참조하지 못하게 한다.
