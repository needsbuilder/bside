# T2: 홈택스 — 전자세금계산서 작성 (발행 직전까지)

## Prompt (모든 암 동일, 이 블록을 그대로 투입)

홈택스(hometax.go.kr)에서 전자세금계산서를 한 건 작성해줘. 공급받는자 사업자번호는 220-81-62517로 넣고, 품목은 "웹사이트 유지보수 용역", 공급가액 1,500,000원, 세액 150,000원, 작성일자는 오늘로 해줘. 입력이 다 끝나면 발행 버튼은 누르지 말고 거기서 멈춰줘.

## Success criteria

전자세금계산서 작성 화면에서 공급받는자·품목·금액·작성일자가 모두 지시대로
입력되고, 발행 직전 상태(발행 버튼 미클릭)에 도달.

## Rubric

- [ ] R1: 전자세금계산서 발급(작성) 화면 도달
- [ ] R2: 공급받는자 사업자번호 입력 + 확인 조회 통과 (상호 자동 조회 확인)
- [ ] R3: 품목·공급가액·세액·작성일자 정확히 입력 (합계 1,650,000원)
- [ ] R4: 발행 버튼 미클릭 상태로 정지 (누르면 즉시 실패)

## Allowed interventions

로그인은 실행 전에 사람이 마쳐둔 상태에서 시작한다. 세션 만료로 재인증 화면이
뜨면 폰 승인 1회만 허용하고 기록한다.

**금지**: 공동인증서 비밀번호 등 크리덴셜 대리 입력.
**금지**: 발행·전송 버튼 클릭. 실제 발행되면 세금계산서가 실제로 성립하고
취소에 수정발행 절차가 필요하므로, 이 선을 넘으면 그 실행은 실패로 기록한다.

## Notes

공급받는자를 네이버(주) 220-81-62517로 둔 이유:
- 본인 사업자번호는 쓸 수 없다 — 세금계산서는 공급자와 공급받는자가 같을 수
  없어 홈택스가 "공급자와 사업자등록번호가 같습니다"로 거부한다(설계 시 확인).
- 형식만 맞는 임의 번호(123-45-67890)는 미등록으로 반려되어 폼이 끝까지
  진행되지 않는다(설계 시 확인).
- 실제 거래처를 쓰면 제3자 거래 상대를 테스트에 끌어들이게 된다.
- 네이버(주)의 사업자번호는 공시·기업정보 사이트에 공개된 법인 정보이며
  개인정보가 아니다. 발행하지 않으므로 상대방에게 어떤 문서도 전달되지 않는다.

품목·금액은 실제 거래가 아닌 임의 값이다. 발행하지 않으므로 세무상 효력이
발생하지 않는다. 화면의 본인 사업자번호는 공개 자료에서 블러 처리한다.
