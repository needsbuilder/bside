# T3: 네이버 지도 — 실제 일정 점심 예약 (예약 직전까지)

## Prompt (모든 암 동일, 이 블록을 그대로 투입)

내일(8월 31일 월요일) 오후 1시에 경기 용인시 기흥구 동백3로11번길 8 (V프라자)에서 미팅이 있어. 그 전에 12시에 근처에서 혼자 점심을 먹으려고 해. 네이버 지도(map.naver.com)에서 V프라자 도보 10분 이내, 12시에 영업 중이고, 기름지지 않은 깔끔한 메뉴(포케·샐러드·한식 백반류)인 식당을 찾아줘. 후보 3곳을 거리·메뉴·가격대·영업시간 비교 표로 정리하고 1순위를 추천해줘. 1순위가 네이버 예약을 지원하면 예약 화면에서 날짜·시간·1명까지 선택하고(최종 확정 버튼은 누르지 마), 예약이 안 되는 곳이면 월요일 12시 영업·브레이크타임 여부를 확인해서 알려줘.

## Success criteria

실존 식당 3곳의 비교표가 실데이터로 산출되고 1순위 추천 근거가 타당함.
1순위가 예약 지원 시: 예약 위젯에서 날짜·시간·인원 선택 도달(확정 금지).
예약 미지원 시: 월요일 12시 영업 여부·브레이크타임을 상세페이지에서 확인.

## Rubric

- [ ] R1: 조건 충족 후보 3곳 발굴 (지도 iframe 탐색 생존)
- [ ] R2: 비교표 4항목(거리·메뉴·가격대·영업시간)이 3곳 모두 실데이터
- [ ] R3: 1순위 추천 + 근거 (도보 시간 조건 충족 확인)
- [ ] R4: 예약 지원 시 선택 도달 / 미지원 시 월요일 12시 영업·브레이크타임 확인
