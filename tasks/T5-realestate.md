# T5: 부동산 — 강남역 단기임대 매물 크로스체크

## Prompt (모든 암 동일, 이 블록을 그대로 투입)

강남역 근처에서 3개월 단기임대가 가능한 투룸 오피스텔을 찾아줘. 조건은 보증금 1,000만원 이하, 월세 200만원 이하야. 네이버 부동산(land.naver.com)과 직방(zigbang.com) 두 곳을 모두 확인해서 매물 5개를 보증금·월세·관리비·면적·층수·강남역까지 거리·등록 중개사(또는 출처 사이트) 표로 정리하고, 같은 매물이 양쪽에 중복 등록된 경우가 있으면 표시해줘. 1순위 추천도 이유와 함께 알려줘.

## Success criteria

두 사이트에서 조건(보증금 1,000만원 이하·월세 200만원 이하·투룸·강남역 인근)에
맞는 매물 5건을 찾아 표로 정리하고, 중복 등록 여부를 확인한 결과가 제시됨.

## Rubric

- [ ] R1: 두 사이트 모두에서 매물 목록 탐색 성공 (한쪽만 성공 시 미충족)
- [ ] R2: 매물 5건이 조건(보증금·월세 상한, 투룸)을 실제로 충족
- [ ] R3: 표 7개 항목(보증금·월세·관리비·면적·층수·거리·출처)이 5건 모두 실데이터
- [ ] R4: 중복 등록 확인 결과 + 1순위 추천 근거 제시

## Allowed interventions

없음. 로그인 불필요한 공개 매물 정보다.

## Notes

문의·연락 버튼은 절대 누르지 않는다(중개사에게 실제 연락이 가면 제3자 피해).
조회·정리까지만 한다. 단기임대 조건은 매물 설명에 명시된 경우만 인정하고,
없으면 "단기 협의 필요"로 표기해도 된다. 네이버 부동산은 지도 iframe +
매물 상세 iframe 구조이고 직방은 SPA라 두 사이트의 구조가 다른 것이 이 과제의
난이도 핵심이다.

## Scoring amendment (2026-08-31, 실행 후)

세 암의 실행 결과, **강남역 인근에 보증금 1,000만원 이하 + 월세 200만원 이하
조건을 만족하는 3개월 단기 투룸 오피스텔은 존재하지 않는다**는 것이 확인됐다
(aside-solo 실행이 네이버·직방 양쪽을 훑어 최저가가 직방 300/260, 네이버
250/240임을 확인). 따라서 R2("매물 5건이 조건을 실제로 충족")는 어떤 암도
달성할 수 없는 항목이므로 **전 암 공통 N/A** 처리하고, T5의 부분 점수는
R1·R3·R4 3개 기준으로 한다. 이는 과제 설계자(우리)의 가격 상한 설정 오류이며,
에이전트의 실패가 아니다. 조건 미충족을 명시적으로 표시한 것은 오히려 정확한
보고로 본다.
